# پروندهٔ نسخه‌دار آزمایشگاه آرتین | Versioned Artin Lab Projects

تحویل مرحلهٔ ۲، ۵ نوامبر ۲۰۲۶: ذخیره/بازخوانی فایل و انتقال پوششی GUM v1 در `/calculators/workspace`.

## رفتار محصول

- «ذخیرهٔ فایل پرونده» فایل JSON روی دستگاه آماده می‌کند؛ پیام برنامه دانلودِ آماده‌شده را اعلام می‌کند، نه ذخیرهٔ قطعی در مقصدی که کاربر انتخاب نکرده است.
- «باز کردن پرونده» ابتدا تمام فایل را اعتبارسنجی می‌کند، سپس پیش‌نمایش بازکردن می‌دهد. پیش‌نویس جاری تا زدن دکمهٔ بازکردن حفظ می‌شود؛ انصراف داده را عوض نمی‌کند.
- وضعیت فعلی ذخیرهٔ دستی فایل است؛ ذخیرهٔ خودکار، تاریخچهٔ سرور و بازیابی از حساب کاربری هنوز اضافه نشده‌اند.
- پروندهٔ جدید `artin-lab-project` نسخهٔ ۱، با id پایدار و savedAt شامل هویت آزمون، مدارک علامت‌خورده، رشته‌های خام استانداردها و مرحلهٔ فعلی است. زبان رابط جزو معنای داده نیست.
- دادهٔ ناقص برای ادامهٔ کار قابل ذخیره است. اعتبارسنجی قالب فایل با اعتبارسنجی عددی و علمی محاسبه متفاوت است؛ صفحه هنوز برای دادهٔ خام نتیجهٔ ساختگی تولید نمی‌کند.

## انتقال GUM

فایل `artin-gum` نسخهٔ ۱ با واردکنندهٔ موجود بررسی می‌شود و در یک پروندهٔ جدید با workflow=`legacy-gum` قرار می‌گیرد. متن دقیق فایل اصلی در legacy.originalText نگه داشته می‌شود. واحدها، علامت حساسیت، مؤلفه‌های افزوده، درجات آزادی، هم‌بستگی‌ها، داده‌های مدل و نمودارها با بازنویسی از روی فرم GC ساخته نمی‌شوند. فیلدهای اضافی موجود در متن اصلی نیز حفظ می‌شوند.

پروندهٔ ترازو یا چگالی به نام GC نمایش داده نمی‌شود. خلاصهٔ نوع مدل، مؤلفه‌ها، واحدها و منبع داده قابل مشاهده است؛ عنوان‌ها و یادداشت‌های اصلی به زبان نوشته‌شدهٔ خودشان باقی می‌مانند. محاسبه و ویرایش بودجهٔ واردشده در محیط جدید هنوز فعال نیست. دکمهٔ دریافت اصل GUM فایل قبلی را برای بازکردن در محیط محاسبات فعلی برمی‌گرداند.

فایل جدید دوباره که ذخیره و باز شود همان originalText را دارد. این انتقال، بازبینی علمی روش یا تأیید نتیجهٔ قبلی نیست. دادهٔ منتقل‌شده برای محاسبهٔ تازه باید در محیط موتور بررسی و مجدداً محاسبه شود.

## قرارداد و محدودیت

- قالب و نسخهٔ ناشناخته، نوع workflow ناشناخته، stage خارج از ۰ تا ۴ و فیلدهای غیررشته‌ای رد می‌شوند.
- استانداردها ۳ تا ۲۰ سطر و دو ستون دارند؛ مقدار خام فارسی، ارقام انتهایی و سلول خالی حفظ می‌شوند.
- شناسهٔ مدرک خارج از فهرست و مدرک تکراری رد می‌شوند.
- سقف فایل ۱۲ MiB، سقف متن اصلی GUM برابر ۴ MiB؛ مؤلفه و نمودار GUM با محدودیت واردکنندهٔ اصلی بررسی می‌شوند.
- فایل و رشته‌ها به عنوان کد اجرا نمی‌شوند؛ متن به صورت خروجی React نمایش داده می‌شود. قالب نسخهٔ بعد بدون مهاجرت صریح پذیرفته نمی‌شود.

build تولید و lint فایل‌های اصلی پاس شدند. موتور عددی سرور در این مرحله تغییر نکرده است. گام بعد، اتصال مسیر GC به محاسبه و ذخیرهٔ اجرای نسخه‌دار است.

## English summary

The new workspace can save and reopen a versioned local JSON project. Opening first validates the complete file and presents a replacement preview. Existing GUM v1 files are validated and wrapped without changing their original text, source notes, units, components, correlations or model data. Non-GC budgets retain their actual method identity. The original GUM file can be downloaded for use in the existing calculation workspace.

This is manual file persistence, not server autosave or automatic scientific approval. Eleven initial file/migration tests passed; live browser checks covered import, actual download, exact original-text preservation, reload/reopen and rejection of an invalid version without clearing the current project.

## اتصال عددی GC، ۵ نوامبر ۲۰۲۶

مسیر جدید اکنون برازش OLS بدون وزن، شیب/عرض از مبدأ و عدم‌قطعیت و هم‌بستگی آن‌ها را از جدول استخراج می‌کند. ورودی‌های پاسخ نمونه، حجم عصاره، ضریب رقیق‌سازی، جرم و بازیابی، با نوع دادهٔ عدم‌قطعیت و منبع هرکدام ثبت می‌شوند. نتیجه با مدل ثبت‌شدهٔ `gcExtraction` از API موجود `/uncertainty/budget` گرفته می‌شود؛ موتور سرور در این مرحله تغییر نکرد.

فیلد اختیاری `gc` به همان قرارداد v1 افزوده شد؛ فایل‌های قبلی بدون آن همچنان باز می‌شوند. `gc.data` داده‌های خام، نوع توزیع/تبدیل، k یا n و منابع را حفظ می‌کند. `gc.run` زمان محاسبه، کلید ورودی‌های همان اجرا، نتیجه، u، U، k و شناسه/نسخهٔ موتور را ثبت می‌کند. نتیجهٔ داخل فایل مورد اعتماد علمی تلقی نمی‌شود: بعد از بازکردن یا تغییر ورودی، تا محاسبهٔ مجدد عدد قبلی نتیجهٔ جاری نیست. دادهٔ GC در پوشش GUM قدیمی پذیرفته نمی‌شود؛ مسیر انتقال قبلی حفظ شده است.

پنج تست جدید برای اعداد فارسی/عربی و علمی، دادهٔ ناقص، برازش و کوواریانس مرجع، برون‌یابی، منبع عدم‌قطعیت، ضرایب گواهی و تکرار، پاسخ نامعتبر سرور و رفت‌وبرگشت اجرای ذخیره‌شده اضافه شد. همراه شش تست پرونده، ۱۱ تست پاس شدند؛ lint و build تولید هم پاس شدند.

در مرورگر واقعی، fixture فرضی با استانداردهای (0,10)، (5,61)، (10,109)، (15,161)، پاسخ 110، حجم 50 mL، ضریب 2، جرم 10 g و بازیابی 80% محاسبه شد: نتیجه 124.6257485 mg/kg، u حدود 2.2402165 و U حدود 4.480433 با k=2. دانلود واقعی حاوی داده و اجرای موتور بود؛ بازخوانی الزام محاسبهٔ دوباره را نشان داد. ویرایش پاسخ به 120 نتیجه را به 137.1008 تغییر داد؛ پاسخ 1000 با پیام خارج از بازه رد شد. کنترل‌های تازهٔ انگلیسی بررسی شدند؛ متن ورودی خود کاربر ترجمه نمی‌شود. در عرض 390 px سرریز افقی کل صفحه وجود نداشت.

محدودهٔ علمی: فرض ناچیز بودن خطای غلظت استانداردها و ثابت بودن واریانس پاسخ؛ عدم‌قطعیت غلظت استانداردها، تکرارپذیری کل روش و اثرهای اضافی در این اتصال نخست به‌صورت خودکار اضافه نمی‌شوند. k دستی است و پوشش دقیق 95% ادعا نمی‌شود. این مسیر تأیید انطباق، اعتبارسنجی کامل روش یا پیاده‌سازی تمام روش‌های GC نیست. توسعهٔ بودجهٔ کامل روش و گزارش رسمی همچنان در نقشه راه باقی است.

### English update

The guided GC external-calibration/extraction path now calls the registered backend model, preserving fit covariance and user-sourced uncertainty inputs. Optional v1 `gc.data` and `gc.run` fields retain raw inputs and a dated calculation snapshot while remaining compatible with older project files. Saved results are unverified on reopen; edited inputs require recalculation. Browser checks covered real API calculation, actual download/reopen, editing, extrapolation rejection, English controls and a 390 px viewport. This is a scoped seven-input budget, not complete method validation or a complete uncertainty assessment of standard preparation and whole-method precision.

## مؤلفه‌های تکمیلی و نمونهٔ جدید، ۵ نوامبر ۲۰۲۶

به `gc.data` فهرست اختیاری `additional` افزوده شد؛ فایل‌های قبلی بدون این فهرست تغییر معنایی نمی‌کنند. سقف ۲۰ مؤلفه و شناسهٔ یکتا، enum نوع داده، هدف و مبنا هنگام بازکردن بررسی می‌شوند. دادهٔ ناقص قابل ذخیره است، ولی برای محاسبه منبع، بررسی هم‌پوشانی و فرض استقلال صریح لازم است. کلید ورودی اجرای ذخیره‌شده، فهرست جدید را نیز دربرمی‌گیرد.

- اثر مشترک استاندارد: عدم‌قطعیت نسبی یک خطای مقیاس مشترک در استانداردها، به‌صورت اثر مرتبهٔ اول بر نتیجه. این قابلیت مدل خطای مستقل غلظت هر استاندارد یا errors-in-variables نیست.
- دقت روش: مؤلفهٔ باقی‌ماندهٔ مستقل از مطالعهٔ روش، به‌صورت مطلق یا درصدی. برای RSD و نتیجهٔ میانگین n تکرار، تبدیل s/√n قابل انتخاب است؛ برای یک نتیجه n=1. این گزینه جایگزین خودکار یا تأیید کل مطالعهٔ Top-Down نیست.
- مؤلفهٔ دلخواه: هدف یکی از پنج ورودی فیزیکی نمونه یا خود نتیجه؛ مبنای مطلق در واحد هدف یا درصدی از همان مقدار. عدم‌قطعیت نسبی در هدف صفر رد می‌شود تا اثر بی‌صدا حذف نشود.

تبدیل درصد به واحد هدف پیش از U/k، a/√3، a/√6، d/√12 یا s/√n انجام می‌شود. `additional_targets` در API موجود استفاده می‌شود تا سرور ضریب حساسیت فیزیکی یا ضریب ۱ برای نتیجه را اعمال کند. هم‌بستگی شیب/عرض از مبدأ حفظ می‌شود؛ این مسیر تازه برای مؤلفه‌های تکمیلی مستقل است. اثر هم‌بسته باید در بودجهٔ پیشرفته با هم‌بستگی صریح ثبت شود. برنامه صحت علمی ادعای عدم هم‌پوشانی را از متن کاربر استنتاج نمی‌کند.

جدول بودجه u، c و |c×u| و نوار مقایسهٔ اندازهٔ اثر را نشان می‌دهد؛ این نوارها درصد واریانس نیستند. جملهٔ کوواریانس برازش جدا با واحد (mg/kg)² نمایش داده می‌شود.

دکمهٔ «نمونهٔ جدید» برای پروندهٔ خالی مستقیم فرم خالی باز می‌کند؛ اگر داده‌ای وجود داشته باشد، dialog بومیِ مستقل با ذخیره، انصراف و ساخت باز می‌شود. تا تأیید، فرم قبلی جایگزین نمی‌شود. انصراف و ذخیرهٔ واقعی قبلی در مرورگر بررسی شد؛ ساخت، شناسه، ورودی‌ها، مدارک، کالیبراسیون و نتیجهٔ پیشین را پاک و مرحلهٔ تعریف آزمون را باز می‌کند. نمونهٔ جدید مسیر GC خارجی/استخراج دارد، نه انتخاب همهٔ روش‌ها. عنوان «عصاره» با «حجم نهایی محلول پس از استخراج» جایگزین شد و مثال فرضی و تفاوت آن با حجم تزریق در هر دو زبان توضیح داده شد.

بررسی عددی: ۱۲ تست frontend و یک مرجع مستقل backend پاس شدند؛ lint و build تولید پاس شدند. در مرورگر، سه اثر فرضی (۲٪ استاندارد، RSD=۳٪ برای n=4، حد رانش جرم ±0.02 g با توزیع مستطیلی) به مثال قبلی افزوده شدند. نتیجه ثابت 124.6257485 mg/kg و U=7.68023797 mg/kg با k=2 بود. عدم ثبت فرض استقلال مانع محاسبه شد. افزودن/حذف مؤلفه و کنترل‌های انگلیسی بررسی شدند؛ فایل واقعی دانلودشده هر سه مؤلفه، منابع و توضیح هم‌پوشانی و اجرای موتور را حفظ کرد و U آن با مرجع مستقل برابر بود.

مبنای راهنمای شناسایی اثرها و اجتناب از دوباره‌شماری: [Eurachem/CITAC QUAM 2012، بخش ۶ و پیوست D](https://eurachem.org/images/stories/Guides/pdf/QUAM2012_P1.pdf)، بررسی‌شده در ۵ نوامبر ۲۰۲۶. این ارجاع تأیید روش یا ادعای انطباق کامل نرم‌افزار نیست.

### English update: additional effects and new samples

Optional additional components now support a shared relative calibration-standard scale effect, independently assessed residual method precision and custom effects mapped to a physical input or the result. Source, overlap assessment and explicit independence are required for calculation. Relative input values are converted to target units before uncertainty conversion. Existing registered backend additional targets supply the sensitivities. A component magnitude table retains the separate fit covariance term rather than presenting misleading variance percentages. This is a first-order extension, not an errors-in-variables calibration or automatic Top-Down assessment.

New sample creation now uses a native modal when existing data needs replacement, with save/cancel/create controls; empty projects open directly. The extraction-volume field now explains its meaning and distinguishes it from injection volume in both languages. Twelve frontend tests, one independent backend reference test, lint and the production build passed. Browser checks confirmed a real extended-budget calculation, blocked unassessed independence, addition/removal, English controls, real download and preservation of all three example effects.

## گزارش قابل چاپ، ۵ نوامبر ۲۰۲۶

در بازبینی GC، پس از محاسبهٔ معتبر دکمهٔ دریافت گزارش HTML و پیش‌نمایش sandbox اضافه شد. گزارش به زبان فعلی صادر می‌شود و شناسنامهٔ نمونه، زمان محاسبه و تهیهٔ گزارش با منطقهٔ Asia/Tehran، مدل و تعریف نمادها، نتیجه و u/U/k، مبنای انتخاب k، استانداردها، **نمودار برداری نقاط کالیبراسیون و خط OLS با محورهای دارای واحد**، پارامترهای برازش، داده‌های خام عدم‌قطعیت و منابع، جدول بودجه با جملهٔ کوواریانس، اثرهای تکمیلی و توضیحات هم‌پوشانی را دارد.

گزارش پیش‌نویس برای بازبینی است؛ فاقد تأیید نهایی آزمایشگاه و تصمیم انطباق. مقدار U و فرمول همان مسیر موجود است؛ موتور در این تحویل تغییر نکرد. گزارش بدون نتیجهٔ معتبر جاری، پس از بازخوانی بدون محاسبهٔ مجدد، یا با داده/کلید/مقدار ناسازگار صادر نمی‌شود. HTML جای فایل JSON قابل ویرایش را نمی‌گیرد. خروجی PDF خودکار پیاده نشده؛ فایل HTML در مرورگر باز و از Print/Save as PDF استفاده می‌شود. CSS چاپ A4 افقی، تکرار سرستون‌ها و حفظ یکپارچگی نمودار/ردیف‌ها را تعریف می‌کند؛ صفحه‌بندی PDF واقعی هنوز جداگانه بررسی نشده است.

HTML بدون وابستگی بیرونی و بدون script تولید می‌شود، ورودی‌های کاربر escape و CSP محدود اعمال می‌شود. پیش‌نمایش داخل iframe با sandbox خالی است. سه تست گزارش برای زبان‌ها، نمودار و تعداد نقاط، وجود منابع/کوواریانس/وضعیت پیش‌نویس، متن تزریقی و رد نتیجهٔ قدیمی اضافه شد؛ مجموع ۱۵ تست هدفمند frontend، lint و build پاس شدند. در مرورگر هر دو گزارش واقعاً دانلود شدند و چهار نقطه، خط برازش و نتیجهٔ U=7.68023797 در فایل‌ها تأیید شد؛ نمودار فارسی در پیش‌نمایش زنده دیده شد. نمونه‌های خروجی و تصویر در `output/lab-workspace-preview/` هستند و دادهٔ واقعی مشتری نیستند.

ترجیح آیندهٔ کاربر: تغییر فونت سراسر اپ به «وزیر / Vazir» در نقشهٔ راه اصلی ثبت شد؛ این تغییر هنوز اجرا نشده است.

### English update: shared standard preparation

A standard-scale component can now derive its relative uncertainty from weighed mass (mg), mass purity (%) and stock volume (mL), with one optional common dilution. Each active quantity retains its nominal, sourced uncertainty type and conversion factor. First-order independent propagation computes concentration and relative standard uncertainty from the raw inputs on every calculation; no stale manually copied percentage is used. Preparation inputs and their sources are preserved in JSON and included in the printable report. Editing preparation resets the GC overlap approval.

This is a common preparation-scale model, not independent calibration-point uncertainty, ready-made CRM dilution, chemical reaction or salt-to-element conversion. Twenty focused tests, lint and the production build passed, including interactive DOM tests in both languages. Live visual review remains pending because local browser use was disabled in Work settings; no browser verification is claimed for this delivery.
