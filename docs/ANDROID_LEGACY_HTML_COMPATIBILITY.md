# سازگاری گزارش HTML با پوستهٔ قدیمی اندروید

۹ نوامبر ۲۰۲۶. تصویر ارسالی کاربر نشان داد محاسبهٔ گفت‌وگوی آزمایشگاهی روی گوشی اجرا شده، اما دریافت گزارش با پیام عدم پشتیبانی نسخهٔ برنامه متوقف شده است.

در کد نسخهٔ قبلی، NativeExport در MainActivity ثبت شده و saveHtml پس از نوشتن و بسته‌شدن stream، URI فایل را برمی‌گرداند؛ getDocumentCapabilities و saveHtmlDocument در آن وجود ندارند. مسیر جدید HTML پیش از فراخوانی ذخیره، قابلیت saveHtmlDocument را الزامی می‌کرد.

saveTextFile اکنون فقط وقتی پروب قابلیت با کد مشخص UNIMPLEMENTED پاسخ می‌دهد، از saveHtml قدیمی Android استفاده می‌کند. این مسیر UTF-8 و نام فایل اعتبارسنجی‌شدهٔ موجود را حفظ می‌کند و URI تأییدشدهٔ content یا مسیر storage/sdcard را لازم می‌داند. پیام موفقیت بدون پاسخ ذخیره صادر نمی‌شود. شکست پروب، شکست ذخیرهٔ جدید و انصراف به ذخیرهٔ دوم یا دانلود Blob تبدیل نمی‌شوند. روش انتخابگر جدید برای پوستهٔ جدید حفظ شده است.

این اصلاح به HTML محدود است؛ پشتیبانی JSON و PDF در اپ قدیمی از آن نتیجه نمی‌شود. وب باید پس از دریافت کامیت دوباره دیپلوی شود. سازگاری با قرارداد قدیمی در آزمون‌ها بررسی شد، اما دریافت فایل با همین اصلاح روی گوشی کاربر هنوز مشاهده نشده است. اگر اپ نصب‌شده NativeExport قدیمی را هم نداشته باشد، به‌روزرسانی بسته همچنان لازم است.

اعتبارسنجی: ۱۲ آزمون منتخب ذخیرهٔ HTML، نمایش وضعیت و گفت‌وگوی آزمایشگاهی موفق؛ TypeScript و build تولید موفق. آزمون‌ها مسیر قدیمی در Android جدید و قدیمی، تأیید URI، خطای ذخیره و عدم تکرار ذخیره پس از انصراف یا شکست مسیر جدید را پوشش می‌دهند.
