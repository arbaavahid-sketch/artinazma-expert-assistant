# بازبینی خروجی مستقل HTML و JSON در اندروید

تاریخ: ۸ نوامبر ۲۰۲۶. وضعیت: پیاده‌سازی و کامپایل پذیرفته؛ آزمون روی گوشی و انتشار باز است.

۱۶ مسیر HTML شامل گزارش‌های توزین، چگالی، GC، تهیهٔ محلول، محلول تجاری، دستور/برچسب رقیق‌سازی، برچسب محلول، مطالعات تکرارپذیری، بایاس، دقت میانی، کالیبراسیون، کنترل، انتقال به GUM، Top-Down، مونت‌کارلو و قاعدهٔ تصمیم به saveTextFile متصل شدند. JSON مستقل ChEBI، NIOSH و CompTox و دریافت GUM اصلی نیز از saveJson مشترک استفاده می‌کنند. محتوای مرجع و منشأ آن حفظ می‌شود؛ JSON مرجع به پروندهٔ قابل‌ویرایش تبدیل نشده است.

Android: قابلیت saveHtmlDocument در protocol1، ACTION_CREATE_DOCUMENT با MIME text/html، نام ASCII محدود به پسوند html، محتوای UTF-8 تا ۱۲MiB و مقصد content URI. JSON و PDF از callback مشترک نوشتن با فرمت صریح استفاده می‌کنند. پیام موفقیت پس از flush و بسته‌شدن stream صادر می‌شود. انصراف، خطای نوشتن و نسخهٔ قدیمی برنامه پیام جدا دارند؛ خطای خام provider نمایش داده نمی‌شود و fallback بی‌صدای WebView وجود ندارد. قفل native میان سه قالب مشترک است و hook کلیک تکراری را در زمان انتظار نادیده می‌گیرد. مسیر قدیمی خروجی گفتگو تغییر نکرده است.

وب: دانلود Blob با UTF-8، حذف لینک موقت و آزادسازی URL پس از ۳۰ ثانیه حفظ شد. شروع دانلود معادل تأیید ذخیرهٔ فایل تلقی نمی‌شود. آزمون جدید مرورگر واقعی در این نوبت انجام نشد؛ تأیید این تغییر بر آزمون خودکار و build متکی است.

اعتبارسنجی:
- کل ۵۷۳ آزمون قبلی frontend در ۸۳ فایل موفق.
- ۷ آزمون تازه در دو فایل موفق: HTML فارسی، محتوای دقیق JSON/منشأ، انصراف، تکرار کلیک، نسخهٔ قدیمی، مقصد نامعتبر، خطای نوشتن و اندازه/نام نامعتبر. آزمون رابط ChEBI محتوای انتخاب‌شده و حفظ رکورد پس از انصراف را بررسی می‌کند.
- TypeScript، lint همهٔ فایل‌های تغییرکرده و build با ۴۸ مسیر موفق.
- compileDebugJavaWithJavac با JDK21 موفق: ۷۴ task، یک اجرا و ۷۳ up-to-date؛ هشدارهای قبلی flatDir/SDK XML/Gradle پابرجا هستند.

APK ساخته/نصب/منتشر نشده است. انتخابگر واقعی، providerهای مختلف، ذخیره و بازکردن HTML/JSON/PDF روی گوشی، فضای کم و رفتار پس از مرگ فرایند هنوز پذیرش لازم دارند. بستهٔ قبلی بدون این متد HTML قابل استفاده نیست و پیام راهنمای به‌روزرسانی/وب می‌گیرد.

دانلود مستقیم فایل گواهی بارگذاری‌شده در ReagentAttachment (PDF/PNG/JPEG با نام اصلی) هنوز مسیر Blob قبلی دارد و از دامنهٔ خروجی‌های تولیدشدهٔ این تحویل جداست؛ باید پیش از پذیرش کامل فایل‌های Android تکمیل شود. فایل گواهی در JSON پرونده همچنان حفظ می‌شود. CompTox همچنان کلید واقعی و پذیرش زنده لازم دارد.


ادامهٔ ۸ نوامبر: در بستهٔ جداگانهٔ filesQa روی گوشی، ذخیرهٔ HTML واقعی با عنوان فارسی و شناسهٔ فرضی، انصراف، پیام کنار دکمه و تلاش مجدد پذیرفته شدند. JSON مراجع و GUM اصلی هنوز آزمون دستگاهی جدا لازم دارند. شواهد و دامنه در ANDROID_APK_FILES_ACCEPTANCE.md ثبت‌اند.
