# طراحی صفحهٔ شروع دستیار آرتین

صفحهٔ شروع در مسیر `/assistant` باز می‌شود. کادر پیام در مرکز صفحه است و موضوع‌های پیشنهادی در شبکه‌ای از کارت‌ها زیر آن قرار دارند.

| جزء | قاعده |
| --- | --- |
| رنگ | آبی آرتین برای کادر و اقدام اصلی و زمینه‌های کم‌رنگ برای تفکیک موضوع‌ها. حالت تاریک توکن‌های جداگانه دارد. |
| خوانایی | از فونت فارسی فعلی آرتین، جهت نوشتار زبان فعال و اندازهٔ خوانا برای توضیح هر مسیر استفاده می‌کنیم. |
| چیدمان | در عرض کافی، کارت انتخاب تجهیزات دو ستون می‌گیرد. در موبایل کارت‌ها زیر هم می‌آیند. |
| اقدام | کارت موضوع متن را برای ویرایش در فرم می‌گذارد. لینک زیر کارت‌ها فضای کار آزمایشگاه را باز می‌کند. |
| حرکت | روی دستگاه دارای ماوس، روشنایی ملایم با حرکت نشانگر درون کارت جابه‌جا می‌شود. حرکت با تنظیم کاهش حرکت غیرفعال است. |
| تصویر | خط طیف در کارت تجهیزات یک تصویر SVG تزئینی است. |

چیدمان مرکزی کادر از [نمونهٔ Claude](https://www.assistant-ui.com/examples/claude)، شبکهٔ کارت‌ها از [Magic UI](https://magicui.design/docs/components/bento-grid) و [Aceternity](https://ui.aceternity.com/components/bento-grid) و بازخورد نشانگر از [Spotlight در Motion Primitives](https://motion-primitives.com/docs/spotlight) الهام گرفته‌اند. کارت‌ها و حرکت‌ها با اجزای فعلی آرتین، CSS و SVG پیاده شده‌اند.
